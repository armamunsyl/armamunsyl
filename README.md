## About Me

I am an **AI-focused builder** working on practical systems around **AI Automation, AI/ML Engineering, RAG, NLP, LLM applications, and AI-powered products**.

My goal is not only to experiment with AI models, but to turn them into **real products, automated workflows, intelligent assistants, and business-ready systems**.

I combine **AI engineering + software engineering** to build solutions that can:

* understand user input
* retrieve the right knowledge
* automate repetitive tasks
* connect with APIs and external tools
* deliver useful output in real-world applications
